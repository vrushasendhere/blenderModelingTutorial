# Easy Studio – Blender Modeling Tutorial

An interactive, browser-based guide to **Easy Studio**, a big-button Blender add-on
that walks you through making a 3D object in five steps (Add → Block → Edit → Detail → Finish).

## Open it

Double-click `index.html` – it opens in any browser, no install or internet needed.

## What's inside

- A clickable copy of the Easy tab: click any button to see what it does, how to use it,
  its shortcut key, its options and a tip.
- Search box (press `/`), guided tour (22 steps), bigger/smaller text.
- Keys: `←` `→` previous / next button, `1`–`5` jump to a step, `Esc` back to overview.
